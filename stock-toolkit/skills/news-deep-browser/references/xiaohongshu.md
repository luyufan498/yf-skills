# 小红书 (xiaohongshu) 排除记录

> 结论：**排除**，不用于 deep-browser 深度浏览补充采集。

## 遇到的错误

### ⚠ IP 风控（"IP at risk 300012"）

- 访问即被风控拦截，提示 IP at risk，频繁触发
- 与其他网站的验证/限流不同，小红书对数据中心 IP 的封控更激进，绕过的性价比极低

## 为什么排除（实证）

1. **IP 风控频繁**：即便从真实 Chrome 登录态访问也常被拦，采集稳定性差
2. **消费向信息密度低**：内容以生活方式/种草为主，对 A 股个股舆情/前瞻信号几乎没有价值
3. 与雪球/知乎相比，无趋势恶化提前量、无深度长文、无基本面讨论

## 若需使用（不推荐）

- 需先解决 IP 风控（住宅 IP/代理），成本高
- 权重建议：雪球 > 知乎 >> 小红书（后者不值得投入）
